# HDCommunity MNG Toolkit

华为云社区 · **管理面 Agent 工具包**（MCP 工具 + Skill）。

让 AI 编码助手（opencode / codex / 码道 等）以自然语言完成社区与成长中心**管理台**的运营操作，例如：

- 博客/评论审核、上下线、置顶、工作台统计
- 任务/权益/白名单配置（涉钱字段走**变更单 + 分级审批**）
- 发放积分 / 发放代金券、记录审计、统计看板

> 本仓库为**脚手架（待填充）**：工具实现与 Skill 将陆续提交。
